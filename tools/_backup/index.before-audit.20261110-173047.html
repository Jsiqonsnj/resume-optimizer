    04 / 优化
    
          
    逐句改：我问，你答
    
          
    
            这里不重复诊断，只做一件事：把值得改的句子摘出来，先问你（这里能不能再具体一点、你具体做了什么），
            再按骨架把你的回答拼成一句能直接替换的话。只重排事实，不新增事实。
          
    
        
    

        
    
          
    
            
    
              
    
                
    可优化的句子 · 一句一句过
    
                —
                —
              
    
              
    
                每条都是我从你简历里摘的原句。三个问题按顺序答，答完点生成 ——
                拼出来的就是能直接替换的那一句。答不出来就空着，我不替你编数字。
              
    
              
    
            
    

            
    
              
    
                
    整份怎么重排（顺序也是信息）
    
                —
              
    
              
    同样的内容换个顺序，读者抓到的重点完全不同 —— 下面是整份简历的调整建议。
    
              
    
            
    

            
    
              
    
                
    导出报告
    
                Markdown
              
    
              
    
                导出的是完整审视报告（与 Python 端 report.to_markdown 同一套模板），可以直接发出去或存档。
              
    
              
    
                
                
              
    
            
    
          
    

          
    
            
    
              
    目标岗位 JD
    
              引擎按它算覆盖度
            
    
            
            
            
    
              0 字
              
    
                
                
              
    
            
    
            
    
              引擎抽词的方式是「词表命中 + 中文 n-gram」，不要求你抄全 JD —— 三段职责加三条要求就够。
            
    
          
    
        
    
      
    

      
      
    
        
    
          
    05 / 规划
    
          
    差什么，补什么，多久补完
    
          
    
            不用点按钮：行业、职能族、JD 缺口一确定，这一页就自动算好了 ——
            补什么证据、考什么证、哪些缺口一周内能补上、3 / 6 / 12 个月各干什么。
          
    
        
    

        
    
          
    
            
    
              
    
                
    按你的行业自动生成的拔高路线
    
                —
              
    
              
    
                依据：引擎识别的行业与职能族、你简历里的缺口词、四层诊断里的硬伤。不是通用课程表。
              
    
              
    
            
    

            
    
              
    
                
    一句话卖点
    
                
              
    
              
    面试第一句就用它，别从「我叫…毕业于…」开始。

    60 秒自我介绍
    
                
              
    
              
    填两个空就能用。这是面试开场，不是简历正文。
